# 设置与窗口行为 · 0.3

原生设置采用顶部分类导航。`⌘,` 或菜单栏“设置…”打开；在扩展查询中打开设置，会直接定位到该扩展。

四个设置页统一为 1000pt 固定宽度。通用、高级和扩展页固定为 648pt 高度，切换插件不会伸缩，较长内容在内部滚动；“关于”页保持约 345pt 的紧凑高度。屏幕空间不足时限制到可用高度减 40pt。切换页面保持窗口顶部位置，靠近屏幕边缘时自动约束到可用区域。标题居中，顶部导航与标题栏一体显示。

设置打开时 Vectracast 显示在 Dock 和应用切换器中；最小化仍保留 Dock 图标。点击 Dock 图标会恢复设置窗口及当前表单。关闭设置后恢复后台模式，主搜索继续由快捷键或菜单栏唤起。

主窗口显示、成为键盘窗口及应用完成激活时，会将输入焦点交给搜索框；激活过程结束后再检查一次，避免恢复到上次点击的结果列表。只有当前可见且激活的主窗口会处理该焦点请求；隐藏窗口时取消待执行请求，正在输入的选区和输入法组字不被重复重置。

首次唤起时，主窗口在目标屏幕的可用区域水平居中，顶部位于距可用区域顶端约 28% 处。拖动后按显示器 UUID 保存水平位置和顶部高度，下次唤起及重启后恢复；屏幕尺寸变化时按比例恢复并约束到可用区域，为 474pt 结果窗口和底部边距预留空间。输入和清空引起的高度变化固定窗口顶部，保持搜索框位置不变。

空搜索时，可拖动输入区域或窗口空白区域：显示居中位置的两条边缘参考线及默认高度参考线，距离目标 12pt 内吸附并显示蓝色轮廓高亮，移出 24pt 后解除吸附以避免抖动。松手、隐藏或失焦后参考线消失。有搜索内容时输入区域保留文字选择，窗口边缘空白仍可拖动，但不显示参考线和吸附高亮。单击空输入仍正常获得焦点。

主窗口使用原生 `NSVisualEffectView` 的 HUD 磨砂材质和窗口背后混合，在磨砂上方叠加稳定底色（深色 84%、浅色 90%），避免亮背景冲淡文字；0.5pt 低对比度边框，浅深色随外观设置变化；系统启用“降低透明度”时使用不透明底色。参考线窗口不接收鼠标事件，也不抢键盘焦点。位置单独保存在 `launcher-position.json`，不触发偏好刷新或扩展查询。

## 通用

- **登录启动**：使用 macOS SMAppService 注册当前应用；失败会显示系统错误。开发包位置应保持固定。
- **Vectracast 快捷键**：点击后在控件上方打开录制浮层，按住 ⌘、⌃、⌥、⇧ 时实时显示键帽，完整组合通过校验后自动保存。至少包含 ⌘、⌃ 或 ⌥；无效或不可用组合在浮层内提示并允许重试。Esc、右上角关闭、点击外部或切换应用取消录制，保留原值；默认 `⌃⌥ Space`。
- **菜单栏图标**：显示/隐藏状态菜单。隐藏后仍可通过快捷键或重新打开应用进入设置。
- **文字大小**：标准/较大，同时改变搜索文字和结果行高。
- **外观**：浅色、深色、跟随系统，主窗口和设置即时更新。
- **窗口模式**：空搜索（含仅空格）统一为 774×100，仅显示输入框与底部操作栏，不展示建议列表。输入后标准模式展开到 474pt，紧凑模式按结果数调整高度。清空后收起列表；空状态可通过底栏按钮或回车打开设置。
- **失焦隐藏**：默认开启。离开主窗口、激活其他应用或点击其他应用时隐藏并取消当前查询；不会主动把焦点抢回 Vectracast。
- **复制后关闭**：可选；默认维持原版复制后显示确认信息的行为。

## 扩展

应用搜索、计算器、翻译和文本工具均是独立插件，在这里启用或停用；高级页不再提供对应的内置功能开关。声明无需关键词执行的扩展会标记“直接输入”。

可搜索已安装扩展及命令名称。表格包含名称、类型、关键词、快捷键与启用状态；右侧显示说明、权限、命令和偏好设置。打开扩展页会读取已校验的商店目录，有新版本时显示“有更新”和行内更新按钮，也可在右侧更新。更新时显示下载与校验状态，失败可重试；开发模式插件不会被商店版本覆盖。

- 修改关键词后回车或结束编辑保存。冲突会被拒绝；安装/启用/回滚也使用实际生效的关键词检查冲突。
- 每个扩展命令使用同一录制浮层配置独立全局快捷键，直接打开其查询前缀。停用扩展后快捷键不会执行命令。
- 原有安装、升级、回滚、卸载、钥匙串凭据继续使用，未迁移或清空用户密钥。

## 高级

支持选择显示屏幕（鼠标所在屏幕/主屏幕）、重新唤起时清空搜索（立即/90 秒后/保留）、Escape 行为（先清空再关闭/直接关闭）；提供开发文档、日志与本地数据目录入口。

## 持久化与当前边界

非敏感应用偏好写入本地数据目录 `preferences.json`。扩展凭据仍单独保存在钥匙串。`window-state.json` 仅记录最近一次主窗口显示/隐藏、焦点、时间等诊断状态，不记录输入或其他应用内容。`dock-state.json` 记录管理窗口的打开状态与 Dock 显示模式；`settings-layout.json` 记录设置页、实际尺寸、内容高度和上限，不包含表单值。

AI、云同步、账号/组织、自定义主题、Hyper Key 等尚未实现；未设置虚假的可用开关。登录启动调用已接入，但未通过重新登录系统验收。

## 0.3 高级设置

- **输入法**：可选择系统当前启用的键盘输入源；默认保持当前输入法。唤起并激活主窗口后切换，关闭、失焦或退出时恢复原输入源。在 Vectracast 中手动切换过输入法时不覆盖该选择；指定输入源不可用会在底栏提示。
- **搜索匹配**：严格为名称精确、前缀、包含匹配；适中增加英文词首字母缩写；宽松再增加从名称开头开始的有序字符模糊匹配。直接匹配始终优先。此策略通过 SDK `ctx.search.sensitivity` 传递，应用搜索插件实现排名，不改变查询防抖。已有完整拼音匹配继续可用。
- **配置导入 / 导出**：版本化 JSON，含应用偏好、快捷键、别名、插件 ID/版本/启用状态和声明的非密钥配置，不含插件代码、钥匙串、日志或登录启动状态。导入先预览，插件缺失或版本不匹配时跳过该插件配置，不自动下载安装；密钥字段、关键词冲突、重复快捷键会被拒绝。导入前将旧配置写入数据目录 `backup-before-import-*.json`，可用同一入口恢复。UI 恢复会实际重新注册快捷键，注册失败保留原配置。窗口位置文件暂不纳入备份。
- **开发模式**：默认关闭；启用后可保持主窗口失焦可见、重新打开保留查询。`platform dev` 已有文件监听，新增读取“自动重建”设置；暂停期间记录修改，恢复后重建。构建中、成功、失败、暂停和停止状态写入 `development/*.json`，可从“构建状态”独立窗口查看时间和错误，每秒刷新。状态是最后一次构建记录，异常终止时可能保留旧状态。查询日志仍不记录正文或密钥。
- **窗口截图**：主窗口按 `⇧⌘S`，或从操作菜单选择。默认复制 PNG；可同时保存到数据目录 `Captures` 并在 Finder 显示。两项均关闭时弹出保存位置选择。只渲染 Vectracast 自身内容，固定背景，不捕获后方桌面，也不请求屏幕录制权限。

CLI 离线备份工具：应用退出时使用 `Vectracast --backup-export <路径>` 或 `Vectracast --backup-import <路径> --apply`，之后重新打开应用。日常恢复优先使用设置中的预览入口。

## 开发工具窗口

高级设置里的开发文档和查询日志分别在 Vectracast 独立窗口中展示，可调整大小、最小化和重新打开。开发文档随应用打包，可离线阅读并切换章节；外部文档链接才交给浏览器。查询日志自动每秒刷新，显示最近 500 条插件、命令、耗时和状态，不显示查询正文或密钥。关闭设置后开发工具窗口保持打开，最后一个管理窗口关闭后恢复后台运行。

设置页切换使用约 180ms 内容淡入淡出及尺寸过渡，主搜索窗口展开/收起也使用尺寸过渡；系统开启“减少动态效果”时取消这些动画。

主搜索窗口从 0.4.3 起即时展开或收起结果区，不使用高度动画；顶部位置不变，标准/紧凑模式的高度规则保留。设置窗口的页面过渡不受影响。
