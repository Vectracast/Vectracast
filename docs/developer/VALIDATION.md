## 0.4.6 Safari 扫描和浏览器类别

- 本机 Safari 的 /Applications 入口为带隐藏标记的符号链接，原 skipsHiddenFiles 枚举漏过它。现在补读应用目录顶层的应用链接，并合并 Launch Services 登记的 HTTP/HTTPS 应用；不遍历隐藏目录或应用内的 helper。
- 按真实路径及 Bundle ID 去重，常规应用目录优先于系统登记的更新缓存。原生测试覆盖隐藏链接、损坏链接、目录外登记、重复 Bundle ID、嵌套 helper 排除及协议元数据。
- 应用搜索插件 0.1.4 按 HTTP/HTTPS 加 HTML 文档声明匹配“浏览器”、browser、liulanqi、llq，避免将仅处理网页 URL 的工具当作浏览器。SDK 新增可选 urlSchemes/documentTypes，旧插件保持兼容。
- 原生构建、TypeScript、严格签名验证通过；最终稳定构建全量 **88/88 通过**。插件原地升级，无新增权限。
- 最终实机 Safari → Safari浏览器；浏览器 → Safari浏览器、Google Chrome、Microsoft Edge 各一条，没有 Edge 更新缓存副本或 ChatGPT。已核对真实应用路径，未启动浏览器或访问页面。

## 0.4.1 历史浏览性能与主窗口对比度

- 顶部输入框按字体的原生单行高度居中，覆盖正常输入、占位文字和较大字号；维持 60pt 顶栏。
- HUD 磨砂上方增加独立、不接收点击的底色层，深色底色 alpha 0.84、浅色 0.90；边框减至 0.5pt，降低透明度时底色完全不透明。没有修改用户主题偏好。
- 缩略图和大预览移至最多两个后台任务，按尺寸区分缓存，共用并发请求；缓存预算 48MiB。图片采集编码改为后台串行任务，维持复制次序。
- 历史索引快照按文件修改时间失效；权限快照同时观察外部数据库版本和当前连接写入。图片返回时重新验证授权与记录存在性；查询防抖期间保留旧预览，但禁止执行旧结果。
- 详情内容相同不重建；筛选结果装载时暂不响应中间的取消选中事件；图片回调携带选择代次，避免快速切换显示错图。
- 全量测试 **83/83 通过**。新增原生测试覆盖后台加载、40 个并发请求合并、缓存复用、不同预览尺寸、缺失文件，以及解码过程中清空、缓存后停用/收回权限、删除与过期。40 个缩略图请求及预览测试本机约 80–91ms，此数字不是整体界面帧率。
- 实机检查类型筛选、连续方向键切换和输入框对齐。磨砂的桌面合成效果不能由单窗口截图完整证明，亮色桌面上的最终观感仍需用户实屏确认。

应用搜索已从宿主迁到 `extensions/applications`，匹配、排序、结果生成由插件完成；底座只提供受权限控制的应用目录与用户触发的打开动作。新增 5 项测试覆盖插件匹配、空输入、权限声明、真实 XPC 查询，以及未声明读取、伪造目标与查询时启动的拒绝。实际主窗口输入 Finder 后显示应用图标及打开动作；在扩展管理停用应用搜索后，CLI search Finder 返回空 items，重新启用后恢复 Finder 结果。截图见 `docs/design/applications-plugin.png`。本轮构建、深度严格签名验证通过。

计算器已从宿主移除，迁入 `extensions/calculator`。宿主以通用 `inputMode: query` 路由无关键词扩展；无匹配返回空结果，显式关键词优先、旧请求取消、跨扩展 ID 隔离。计算器相关测试包含 26 项计算/manifest 用例、真实 XPC 计算结果、空关键词接入、输入权限变更确认、多扩展合并和原有运行时回归。取消回归同时覆盖单命令与无关键词协调器。

实际界面：`12 * (100) +50` 与 `12 ×（100）＋50` 均得到 1250；`0xff03` 展示十/十六/二/八进制。选中十六进制回车复制后粘贴回搜索框，读回为 `0xFF03`。通过扩展管理停用计算器后，CLI 无关键词查询返回空 items；重新启用后恢复四条结果。截图见 `docs/design/calculator-implicit.png`。本轮没有读取有道密钥或调用翻译网络服务。

整数使用 BigInt 有理数运算；输入 256 字符、十进制单个数字 128 位、分子/分母 4096 位二进制上限。小数最多输出 20 位，未完整表示时标注约值；不包含位运算、单位换算或数学函数。完整语法见计算器扩展 README。

## 尚未验收或实现

1. **有道覆盖范围**：用户已在本机保存凭据，原生界面已获得 `yd apple → 苹果` 的真实响应。当前仅验证这一查询，不代表全部语种与异常分支都完成真实服务验收。
2. **中文 IME、多屏与全屏 Spaces**：实现了 markedText 防误执行、鼠标屏幕定位和焦点逻辑，但未完成真实输入法/多屏组合验收。
3. **调试器**：开发 JSContext 可检查、产物内嵌 source map，尚未验证 Safari TypeScript 断点和暂停恢复。日志只有结构化宿主指标，console 转发未实现。
4. **公开商店安全**：尚无发布者签名、撤回、审核、来源验证、严格内存上限、DNS 重绑定防护。网络按声明的 HTTPS origin 限制，不是完整 SSRF 防护。不要分发为可任意安装陌生扩展的正式产品。
5. **运行时资源**：同步 JS 无主动取消，依靠 watchdog 终止；XPC 服务资源仍需进一步隔离。取消旧查询已经取消其网络并作废回调，不能保证立刻结束其所有 JS 计算。
6. **发行与兼容**：只验证本机 Apple Silicon；macOS 13.3 是编译部署目标，未逐版本验证。未做 Intel、Developer ID 公证、安装器、自动更新和其他机器安装测试。
7. **SDK 后续**：React 组件、流式结果、AbortSignal、自定义存储、扩展测试工具包、第三方生态兼容适配尚未实现。
8. **产品后续**：商店、AI、同步、文件索引、片段、窗口管理等仍在方案中。剪贴板历史与可搜索动作面板已实现；动作面板的自动退出、禁用应用等能力尚未加入。

## 结论

这是 A+B 阶段的可运行开发预览，尚未达到方案中 A+B 全部验收门槛，更不等于完整平台或可公开发行产品。下一步优先补齐更多翻译场景、IME、稳定断点链路与资源限制，再进入组件与商店阶段。

## 0.5.0 应用操作面板

- 应用插件 0.2.0 输出打开、Finder 定位、简介、包内容、收藏动作及 SF Symbol/快捷键；宿主统一渲染右下角可搜索浮层。
