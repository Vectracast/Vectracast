# 产品与交互规格

状态：已确认的完整产品目标；当前已实现开发预览子集，实际范围见 [验证记录](../developer/VALIDATION.md)。

## 1. 产品原则

主搜索框是工作入口。输入 `yd apple` 时，用户已经选择了翻译并给出了内容，系统应立即查询，不能再要求回车进入翻译页面或重新输入。

将交互分成三种能力：

- **查询**：根据输入返回可选择结果，如翻译、文件、书签、剪贴板。
- **动作**：用户选中结果后执行，如复制、打开、粘贴、移动窗口。
- **工作区**：用户主动展开时提供多步骤操作，如编辑笔记、设置扩展、多轮 AI 对话。

同一扩展可以同时提供三种能力。工作区不能成为查询结果的必经入口。

## 2. 功能全景

以下为完整功能规划。各项按依赖分期建设，当前可用功能以开发预览与验证记录为准。

阶段简称：A 基础内核；B 首个扩展闭环；C 开发者预览；D 商店测试；E 日常工具完善；F 云端与高级能力。详细门槛见交付文档。

## 3. 统一键盘协议

| 输入 / 操作 | 规则 |
| --- | --- |
| 输入 `yd` | 优先显示翻译入口和参数提示；不发送空查询 |
| 输入 `yd ` | 在原搜索框进入翻译查询范围；光标不跳到另一个页面 |
| 输入 `yd apple` | `apple` 自动传给匹配扩展；结果直接占据列表 |
| ↑ / ↓ | 移动结果选择，不改写输入 |
| Return | 执行所选结果的主动作；翻译默认复制 |
| ⌘Return | 可用时执行次动作；翻译为粘贴回之前的应用 |
| ⌘K | 打开当前结果的动作面板，继续输入搜索动作 |
| Tab | 接受选中的补全；没有补全时不执行隐含动作 |
| ⌘1…9 | 执行屏幕内对应结果的主动作；可在设置关闭 |
| Esc | 先关闭动作/预览，再退出查询范围，最后关闭窗口；保留可恢复的输入 |
| Backspace | 普通文本编辑；不得强行把完整查询变成不可编辑的标签 |
| 中文输入法选词 | 组合输入期间 Return 交给输入法，不执行结果动作 |

精确别名优先于模糊匹配；大小写不敏感；注册冲突时要求选择或改名，不能静默覆盖。未知前缀仍按普通文本检索，不隐式发给外部 AI。

不带前缀时只运行默认启用的本地检索；联网扩展须命中关键词或由用户显式选择。用户可以开启特定扩展的无前缀联网查询，但应在配置处清楚显示这一行为。

## 4. 翻译样板的完整流程

1. 安装有道扩展，填写应用 ID 与密钥，关键词默认建议 `yd`。
2. 输入 `yd apple`。先显示查询状态，停止输入短暂间隔后发送请求。
3. 依次展示接口真实返回的翻译、基础释义和网络释义。没有对应字段时不生成占位条目。
4. 每条结果有稳定 ID、文本、来源类别；详情显示词性等可用信息。复制值与展示标签分离。
5. Return 复制选中条目的纯结果；⌘Return 粘贴；动作面板可切换目标语言、查看原文、重试。
6. 改为 `yd orange` 时取消旧查询。旧 `apple` 响应不得重新占据结果列表。
7. 凭据缺失时，列表内显示「配置有道」，填写后原查询自动恢复。
8. 无网络、余额不足、鉴权失败、限流分别显示原因；不展示伪造的备用结果。

是否接入发音、例句、同义词，取决于官方接口实际返回与服务权限，不以界面需要反向编造数据。

## 6. 视觉与体验验收

视觉验收以 Vectracast 的界面规范和场景截图为准，检查各页面的布局与操作是否一致。

需覆盖：空主框、混合结果、`yd` 查询、详情分栏、动作面板、设置、扩展管理、商店详情、加载与错误。对比项目包括窗口尺寸、字体、基线、行高、图标比例、选中态、分隔线、圆角、阴影及动效。

支持系统深浅色、减少动态效果、VoiceOver、中文输入法、键盘全流程。主框高度应稳定，异步结果到达时不让用户已经选中的条目跳位。多屏和全屏应用下必须测试唤起位置及焦点归还。
